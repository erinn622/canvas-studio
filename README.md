# Canvas Studio

一个面向图片拼贴与自由绘画的轻量 Web 画布编辑器。

## 当前原型

- 自定义画布尺寸
- 单张/多张图片导入
- 图片拖动
- 铅笔、钢笔、水彩、马克笔、蜡笔、橡皮、吸管、移动工具
- 笔刷大小 / 透明度 / 平滑度
- 羊皮纸、水彩纸、宣纸、素描纸纹理
- 撤销 / 重做
- 缩放 / 平移
- PNG / SVG 导出
- 键盘快捷键

## 下一阶段建议

1. 真正的图层系统
2. 图片缩放、旋转、裁剪与锁定
3. Bezier 钢笔工具
4. Apple Pencil / Pointer Events 笔压
5. 更真实的水彩、蜡笔、纸张纹理
6. 选区、蒙版、混合模式
7. 项目文件保存（JSON）
8. PWA 离线使用
9. 响应式移动端布局
10. GitHub Pages 自动部署

## 本地运行

直接双击 `index.html` 即可打开原型。

也可以用任意静态服务器运行。

## GitHub Pages

把项目推送到 GitHub 后，在仓库 Settings → Pages 中选择从 `main` 分支部署即可。
